# 📝 ToDo List — Приложение для управления задачами

Простое и удобное веб-приложение для управления списком задач с современным интерфейсом и расширенной функциональностью.

---

## 📁 Структура проекта

```
ToDoList/
├── index.html # Главная страница приложения
├── src/ # Исходные файлы
├── css/ # Стили проекта
├── js/ # JavaScript файлы
│ ├── script.js 
│ ├── createTask.js # Функционал создания задач
│ ├── editTask.js # Функционал редактирования задач
│ ├── modal.js # Управление модальными окнами
│ └── search.js # Поиск и фильтрация задач
├── scss/ # Исходные SCSS-файлы
│ ├── main.scss # Главный SCSS файл
│ ├── base/ # Базовые стили
│ ├── components/ # Компоненты
│ ├── layout/ # Макеты страниц
│ ├── themes/ # Темы оформления
│ └── utils/ # Утилиты и миксины
└── README.md

```

---

## 🛠️ Технологии

- **HTML5** — семантическая разметка  
- **SCSS (Sass)** — препроцессор CSS с модульной структурой  
- **JavaScript** — интерактивность и логика приложения  
---

## 💡 Основные функции

✅ **Создание задач** — быстрое добавление новых задач  
✏️ **Редактирование задач** — изменение существующих задач  
🔍 **Поиск и фильтрация** — удобный поиск по задачам  
🗑️ **Удаление задач** — удаление ненужных задач  
📱 **Адаптивный интерфейс** — работа на любых устройствах  
🎨 **Модальные окна** — интуитивное взаимодействие с пользователем
